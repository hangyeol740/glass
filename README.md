# 모닝듀 · 작은 유리정원

Three.js 기반 복셀 스마트팜 게임입니다. 다른 게임이나 로비 없이 이 게임만 독립 실행합니다. 그래픽과 사운드는 코드로 생성하며 외부 이미지·모델·음원을 사용하지 않습니다.

## 실행

Node.js 22.12 이상 또는 Vite 8이 지원하는 최신 LTS 버전이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 주소를 열면 바로 게임이 시작됩니다.

```bash
npm test
npm run build
npm run preview
```

배포할 때는 `dist/` 내용을 정적 호스팅에 올리면 됩니다. 상대 경로 설정으로 하위 경로에서도 실행할 수 있습니다.

## 플레이

- 지도에서 하우스를 선택하거나 빈 부지에 새 하우스를 건설합니다. 최대 12동이며 2동째 100 G부터 건설비가 증가합니다.
- 하우스별 작물·센서·배선·장비·환경은 독립 관리합니다. 선택하지 않은 하우스도 계속 성장합니다. 골드·수익·시간·날씨는 공유합니다.
- 씨앗 선택 후 빈 두둑 클릭으로 심고, 성장 완료 후 클릭 또는 모두 수확으로 수확합니다.
- 미스트·식물등 스위치와 환기 슬라이더, 온실 측면 레버를 조작합니다.
- 센서는 상점 구매 후 온실 바닥을 클릭하여 설치합니다. ESC로 취소할 수 있습니다.
- 배선 모드에서 센서 OUT을 장치 IN까지 드래그하고 조건을 편집합니다. 수동 조작하면 해당 자동 연결은 해제됩니다.
- 봄 새잎·꽃잎, 여름 녹음, 가을 단풍·낙엽, 겨울 가지·눈으로 계절을 표현합니다. 낮밤 조명은 부드럽게 전환됩니다.
- 소리 버튼을 누르면 Web Audio 합성 효과음이 활성화됩니다.
- 하루는 4분, 계절은 4일입니다. 일시정지 및 1×/3×/6× 속도를 지원합니다.
- 브라우저 localStorage 자동 저장. 숨겨진 탭은 정지하며 오프라인 진행은 없습니다.

## 구조

- `src/main.js`: 게임 루프와 입력
- `src/data/`: 작물·상점·계절 데이터
- `src/engine/voxelRenderer.js`: 복셀 3D 렌더링
- `src/engine/farmPhysics.js`: 성장·환경·경제
- `src/engine/estate.js`: 여러 하우스와 저장 이전
- `src/engine/sensorSystem.js`: 센서와 자동화
- `src/engine/dayLighting.js`: 연속 낮밤 조명
- `src/engine/audio.js`: 효과음 합성
- `src/engine/storage.js`: 저장 검증
- `src/ui/`: 모니터·상점·지도·스타일
- `tests/`: 게임 로직 및 계절·복셀 테스트

환경 수치는 게임용 근사 모델로 실제 농업 제어용이 아닙니다. WebGL 지원 브라우저가 필요합니다.
